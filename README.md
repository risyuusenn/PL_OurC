# Our-C Interpreter

A C++ implementation of an interpreter for **Our-C**, a simplified C-like programming language.

## Features

- Lexical analysis and syntax parsing
- Variables, arrays, and functions
- Arithmetic, logical, and assignment operations
- Control flow: `if`, `else`, `while`, `do-while`
- Function calls and `return`
- Basic `cin` / `cout` support
- Runtime memory and scope management

## Language

C++
